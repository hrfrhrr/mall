# 02 · 后端工程结构与开发规范

## 1. 工程结构

```
亿级高并发电商项目/
├─ pom.xml                       # 父 POM（统一版本/BOM/插件）
├─ baizhan-common-core/          # 通用内核：Result/分页/异常/ID 生成
├─ baizhan-common-security/      # 安全内核：JWT/密码工具/服务级鉴权拦截器/UserContext
├─ baizhan-api/                  # 跨服务 Dubbo 接口与 DTO（provider/consumer 共用）
├─ baizhan-auth/                 # 认证服务（演示：登录/注册/令牌校验）
├─ baizhan-user/                 # 用户服务（演示：我的信息/收货地址）
├─ baizhan-product/              # 商品服务（演示：分页/详情 + Redis 缓存 + Dubbo Provider）
├─ baizhan-order/                # 订单服务（演示：Dubbo 取价/下单/查询 + RocketMQ 异步）
├─ frontend/                     # Vue3 管理后台
├─ mobile/                       # uni-app 多端（H5/微信小程序）
├─ docker/                       # Compose、初始化 SQL、镜像构建
└─ docs/                         # 方案文档
```

## 2. 父 POM 版本对齐（重要）

Spring Boot / Spring Cloud / Spring Cloud Alibaba 三者版本必须严格对齐：

| Spring Boot | Spring Cloud | Spring Cloud Alibaba |
|---|---|---|
| 3.2.x | 2023.0.x | 2023.0.1.x |
| 3.3.x | 2023.0.3.x+ | 2023.0.3.x |

本项目锁定：**Boot 3.2.10 / Cloud 2023.0.1 / Alibaba 2023.0.1.0 / JDK 17**。

## 3. 新增一个微服务的标准步骤

1. 父 `pom.xml` 的 `<modules>` 注册新模块；
2. 新建目录 `baizhan-xxx/pom.xml`，依赖：
   - `com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-discovery`
   - `com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-config`（可选）
   - `com.baizhan:baizhan-common-core`
   - `com.baizhan:baizhan-common-security`（需要 JWT 鉴权必加，配置 `baizhan.jwt-auth` 白名单）
   - `org.apache.dubbo:dubbo-spring-boot-starter` + `dubbo-registry-nacos`（需要 RPC 时）
   - `com.baizhan:baizhan-api`（对外提供/消费 Dubbo 服务时）
   - `com.baomidou:mybatis-plus-spring-boot3-starter`（用 DB 时）
   - `com.github.xiaoymin:knife4j-openapi3-jakarta-spring-boot-starter`
3. 启动类：`@SpringBootApplication(scanBasePackages = "com.baizhan.mall")` + `@ConfigurationPropertiesScan(basePackages = "com.baizhan.mall")`（Dubbo 服务另加 `@EnableDubbo`）
4. `application.yml` 配置见下表；
5. `docker-compose.yml` 增加部署单元（统一环境变量注入）；
6. `docker/higress/data/ingresses/` 增加该服务的 Ingress 路由（一个服务一个 YAML 文件）。

## 4. 服务通用配置模板

```yaml
server:
  port: 91xx
spring:
  application:
    name: baizhan-xxx          # 注册到 Nacos 的服务名
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://${MYSQL_HOST:localhost}:3306/baizhanshopping?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true&rewriteBatchedStatements=true
    username: ${MYSQL_USER:root}
    password: ${MYSQL_PASSWORD:baizhan123}
  data:
    redis:
      host: ${REDIS_HOST:localhost}
      port: 6379
      password: ${REDIS_PASSWORD:baizhan123}
  cloud:
    nacos:
      discovery:
        server-addr: ${NACOS_SERVER:localhost:8848}
      config:
        server-addr: ${NACOS_SERVER:localhost:8848}
        import-check:
          enabled: false        # 演示环境不强制要求 Nacos 配置存在
mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  configuration:
    # 本项目数据库列名为驼峰（nickName/goodsName），必须关闭下划线转驼峰
    map-underscore-to-camel-case: false
# 服务级 JWT 鉴权（密钥必须与 baizhan-auth 一致；skip-paths 按需放行公开接口）
baizhan:
  jwt:
    secret: ${BAZHAN_JWT_SECRET:YmFpemhhbi1tYWxsLWp3dC1zaWduLXNlY3JldC0yMDI0LTAxLTAx}
    expiration: 7200
  jwt-auth:
    skip-paths: []
# Dubbo（如本服务需要 RPC；application.name 必须与 spring.application.name 区分，
# 否则 Dubbo 的 20880 实例会混入 Spring Cloud 服务列表，导致网关路由错实例）
dubbo:
  application:
    name: ${spring.application.name}-dubbo
    qos-enable: false
  registry:
    address: nacos://${NACOS_SERVER:localhost:8848}
  protocol:
    name: dubbo
    port: 20880
knife4j:
  enable: true
```

## 5. 编码红线

- 任何业务异常抛 `BizException`，由 `GlobalExceptionHandler` 统一包装为 `Result`；
- 禁止在 Controller 中写业务逻辑；
- 涉及金额一律 `BigDecimal`，禁止 `double`；
- 所有配置支持环境变量覆盖（`${ENV:default}`），保证同一镜像多环境复用；
- 日志使用 SLF4J `@Slf4j`，禁止 `System.out`。
